# Signaler une vulnérabilité

Utilisez le signalement privé GitHub dans l'onglet **Security** du dépôt lorsqu'il
est disponible. N'ouvrez pas d'issue publique avec des clés Cloud, mandats privés,
contenus de mémoire, journaux clients ou procédures permettant de viser un client.
À défaut, contactez l'équipe via les coordonnées du site https://basira.sawm.io/.

Ce dépôt est une référence d'intégration : ses protections ne constituent pas une
certification ni un antivirus général. Le modèle Cloud ne reçoit pas de shell
root. Les actions déléguées restent soumises aux contrôles de l'exécuteur local.

Lisez [le modèle de sécurité](docs/SECURITY-MODEL.md) avant de connecter un serveur.
Conservez le dashboard sur loopback, les clés hors du dépôt et les charges de
validation dans une VM dédiée avec données fictives.
